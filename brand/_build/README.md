# Brand build

Every SVG and PNG in `brand/` is generated by these scripts, so the marks stay identical
across files. Change a value here, then rebuild; don't edit the SVGs by hand.

```bash
python3 -m venv .venv && .venv/bin/pip install fonttools uharfbuzz resvg-py pillow
.venv/bin/python run_all.py
```

| Script | Makes |
|---|---|
| `lib.py` | Palette, leaf geometry, outlined type, the two wordmarks, rendering |
| `concepts.py` | `concepts/` and the comparison sheet |
| `logo.py` | `logo/`: marks, small marks, wordmarks, lockups, construction, pair |
| `icons.py` | `icons/`: favicon.svg/.ico, PNG sizes, avatar |
| `banners.py` | `social/og-image.*`, `readme/hero-*.svg` |
| `guidelines.py` | `guidelines.html`, with contrast ratios computed from the palette |
| `overview.py` | `overview.png`: the identity on one board |
| `review.py` | `previews/`: PNG renders and contact sheets for checking |
