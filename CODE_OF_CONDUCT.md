# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep feedback about the work, and don't harass anyone. Maintainers may remove comments, commits or contributors that don't meet this standard.

Report unacceptable behavior privately to the maintainer through the contact details on the [maintainer's GitHub profile](https://github.com/jmjohns9).
